# Tropical Fresh 🌴🥭

Website/aplikasi katalog dan pemesanan minuman tropical yang siap di-upload ke GitHub Pages.

## Cara menjalankan
1. Upload semua file ke repository GitHub.
2. Pastikan `index.html` berada di root repository.
3. Buka **Settings → Pages** di GitHub.
4. Pilih **Deploy from a branch**, branch `main`, folder `/ (root)`, lalu Save.
5. Tunggu beberapa menit, lalu buka URL GitHub Pages yang diberikan GitHub.

## Fitur
- Responsive untuk HP dan desktop
- Katalog minuman dengan foto produk dari Unsplash
- Filter kategori dan pencarian
- Detail produk
- Pilihan ukuran, gula, dan topping
- Keranjang belanja dengan localStorage
- Checkout sederhana
- Promo dan best seller
